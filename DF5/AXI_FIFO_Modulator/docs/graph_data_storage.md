# Де зберігаються дані для графіків на платі

Коротко: **окремого файлу з даними на платі немає**. Сигнал генерує сам MicroBlaze, обробляє його
блоками по 256 відліків, а для екранів лишає лише стиснутий запис. Усе це живе в 32 КБ BRAM
усередині FPGA і зникає після вимкнення живлення.

## 1. Звідки береться сигнал

Тестовий I/Q-сигнал синтезує сам MicroBlaze у функції `src_synth_read()`
([`vitis/src/source/src_synth.c:5`](../vitis/src/source/src_synth.c)):

* 2-FSK на −250 кГц від центру, девіація ±50 кГц, 19.2 кбіт/с, дискретизація 4.5 МГц;
* пакети по 192 біти (32 біти преамбули 0101…, далі псевдовипадкові), паузи по 128 біт, плюс шум.

Ні `vivado/sources/sim_data/sim.iq`, ні SD-карта, ні RTL-демодулятор тут **не задіяні**.

## 2. Як робиться запис

1. Після старту ≈3.6 мс прогріву (оцінки рівня шуму встигають встановитись).
2. Запис чекає **кінця пакета**, щоб почати в паузі.
3. Наступні 36.4 мс (163 840 відліків) — запис. У нього потрапляють **два повні пакети** з паузами.
4. Далі картинка стоїть, кнопки лише перемальовують її з тих самих даних.

## 3. Де лежать дані

Уся пам'ять процесора — 32 КБ LMB BRAM (адреси `0x0000–0x7FFF`): код, дані й стек разом.

| Що | Де в коді | Розмір | Для якого екрана |
|---|---|---|---|
| Поточний блок I/Q | `iq[]`, `vitis/src/main.c:26` | 1 КБ | лише 256 відліків, кожен блок перезаписує попередній |
| Обвідна сирого I/Q | `raw[384]`, `vitis/src/app/capture.h:44` | 1.5 КБ | RAW I/Q: min/max I і Q на кожну з 384 колонок, крок 64 одиниці АЦП (int8) |
| Декодовані біти | `pkt[2]`, `vitis/src/app/capture.h:48` | ≈90 Б | BITS: для кожного пакета — початок, кінець, до 256 бітів |
| Waterfall | `wf[40][128]`, `vitis/src/app/capture.h:57` | 5 КБ | WATERFALL: 40 рядків по 0.9 мс × 128 бінів (±1.125 МГц) |
| Спектр | `fft[128]`, `vitis/src/app/capture.h:56` | 128 Б | FFT: max hold по рядках waterfall |
| Робочі буфери FFT | `fft_re/fft_im`, `wf_acc`, `mag` | 1.8 КБ | тимчасові, лише під час запису |

**Сирі відліки не зберігаються.** З 163 840 відліків лишаються лише ці підсумки. Тому
максимальний зум (×16) показує обвідну, а не окремі відліки.

## 4. Як показати саме `sim.iq`

* **Читати файл із SD-карти** — це Блок 2 з ТЗ (`../../readme.md`).
* **Вшити фрагмент `sim.iq` у прошивку** — але в 32 КБ BRAM поміститься лише ~1 мс сигналу.
